# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址，选择服务商并填写授权码或 App 专用密码。不要把密码发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |

以服务商当前页面为准，岛仔设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；岛仔不会替你改变系统网络设置。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文按标题、段落、列表、引用分行排版（HTML 邮件不再压成一整段纯文本），正文内的网页链接交给默认浏览器打开。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予岛仔日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、定时、饮水与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

### 定时提醒（站立与自定义）

「设置 → 专注与定时」分组下有五个并列子项：专注、饮水、站立提醒、抽烟提醒、自定义定时。前四个和专注、饮水一样，都能在「页面管理」里单独开关、单独上岛。

**站立提醒**子项：打开开关，设置提醒间隔与生效时段。

**抽烟提醒**子项：开关、间隔、生效时段、每日上限（0 = 不限），以及今日记录与近 7 天柱状图；点「抽了一根」记一条，「撤销上一根」可以改错。记录只写在本机 `smoke.json`。

**自定义定时**子项：自己填写标题和内容：

- **标题 / 内容**：提醒卡片上显示的文字，内容可留空。
- **方式**：「间隔提醒」每隔 N 分钟（1–720）循环；「每日时刻」每天在 HH:MM 触发一次。
- **生效时段**：起止小时相同表示全天，跨夜如 22 时至 6 时同样支持；时段外不弹提醒。
- **启用**：每条可单独开关；列表里可编辑、删除，通知卡片上的「稍后」会在 10 分钟后重弹一次，「定时设置」直接回到本页。

定时提醒列表保存在数据目录的 `timers.json`，与其他数据一起迁移。程序退出、关机或睡眠期间不会补发提醒。

### 岛上的三个提醒页

岛展开后左右翻页可以到「自定义定时」「站立」「抽烟」三页，它们和音乐、专注、饮水一样在「设置 → 页面管理」里单独开关、拖动排序。

- **自定义定时**：左边是提醒条数与开启数，右边列出前三条。**每行左侧是独立开关**，点开关只切换；点标题才进入编辑（会带着这条提醒的表单）。左下角「新建提醒」直接开新表单。
- **站立**：显示下一次提醒的倒计时、间隔与生效时段，右侧一个大开关，左下角进设置。
- **抽烟**：左上是大数字（今日根数，超过每日上限变红）、距上一根的间隔，下面是「抽了一根」「撤销」；右侧是近 7 天柱状图和下次提醒时间。

## AI 额度

先登录相应工具，再在岛仔 AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的本机登录由原工具管理，岛仔不会修改它们的配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

**WorkBuddy 连接**有三种方式，按推荐顺序：

1. **自动获取登录态（推荐）**：点一下会用**独立配置**的 Edge 打开官网，在里面完成登录即可，岛仔会自己把会话读出来并验证，不用 F12、不用复制，窗口留着或关掉都行（读到登录态后会自动关闭）。这个窗口用的是独立配置目录（`%LOCALAPPDATA%\Daozai\login-profile`），不读取也不改动你日常浏览器的 Cookie。登录成功后如果还没跳转，多等两三秒；读到的是登录过程中的中间态时会自动重试。
2. **手动粘贴 Cookie**：没有装 Edge 时用。只复制 `session` 这一条的值也可以，岛仔会自动补成 `session=…`。
3. **用浏览器扩展连接**：依赖本机 `127.0.0.1:10086` 的第三方桥接，装了才用得上。

官方客户端本机登录态无法复用：新版 WorkBuddy 把 accessToken 做了信封加密，只能由它自己的主进程解密，第三方程序（包括岛仔）读不到。

关于安全与有效期：岛仔只保留 `session`、`session_2`、`cb_login_mode`、`cb_login_realm` 四个登录 Cookie，其它站点凭据一律丢弃；会话用当前 Windows 用户的 **DPAPI** 加密后保存在本机数据目录，只会发往 `www.workbuddy.cn` / `www.codebuddy.cn`，不会上传到任何第三方。官网的登录态通常 30 天有效，过期后刷新会提示「登录已过期」，此时重新粘贴一次 Cookie 即可；重新连接已有账号时，Cookie 必须属于同一个 WorkBuddy 账号。

## 更新、卸载与数据目录

双击新版 `Daozai-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\Daozai`，可改为其他有写入权限的文件夹。

用户数据默认保存**在程序目录下的 `data` 文件夹**（单文件版就是 exe 旁边），整个文件夹拷走即可迁移。若安装目录不可写（例如装在 `Program Files` 且没有管理员权限），会自动退回 `%APPDATA%\Daozai`。从旧版本升级时，首次启动会把 `%APPDATA%\Daozai` 里的旧数据复制到 `data`，旧目录原样保留。

### 更改数据文件位置

打开「设置 → 常规 → 数据文件位置」，可直接输入绝对路径或点「浏览…」选文件夹，再点「更改并迁移」。岛仔会检查目录可写，把设置、待办、饮水、定时提醒、置物、邮箱与日历配置、AI 额度、歌词与凭据缓存等复制到新目录（目标已存在的文件不覆盖，原目录保留作备份），然后写入引导文件 `%APPDATA%\Daozai\data-dir.txt`。**重启岛仔后完全生效**。「恢复默认」会删除引导文件并把数据复制回默认目录（程序目录下的 `data`）。

注意：

- 环境变量 `DAOZAI_DATA_DIR` 优先级更高，设置它时界面里的更改不会生效。
- 邮箱、日历密码保存在 Windows 凭据管理器，不属于数据文件，切换目录后仍可读取。
- 更新缓存 `%LOCALAPPDATA%\Daozai\Updates` 与单实例互斥体不随数据目录变化。
- 两个不同数据目录的实例仍受单实例互斥体限制，不能同时运行。

升级安装保留数据。若提示岛仔正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在岛仔设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查岛仔是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。
