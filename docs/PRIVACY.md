# 隐私与安全

## 本机数据

岛仔默认在**程序目录下的 `data`** 保存用户设置、待办、本机日程及提醒设置、饮水记录、定时提醒（`timers.json`）、抽烟记录（`smoke.json`，只有本机时间戳）、置物文件路径、连接元数据以及忽略的邮件日程标识；安装目录不可写时改用 `%APPDATA%\Daozai`。可在「设置 → 常规 → 数据文件位置」更改目录，或用环境变量 `DAOZAI_DATA_DIR` 指定另一目录；更改时数据会被复制到新目录，原目录仍保留一份。引导文件固定为 `%APPDATA%\Daozai\data-dir.txt`，只记录目录路径。定时提醒的标题与正文、抽烟记录都只保存在本机，不发送到任何服务。WorkBuddy 连接优先识别本机客户端的当前登录，识别不到时才在默认浏览器完成官网授权；岛仔只保存官网下发的访问/续期令牌，不读取也不修改浏览器 Cookie 或客户端配置。置物架保存原文件路径，不复制文件正文。本机日程不上传到工作日历。

邮箱和日历密码通过 Windows 凭据管理器保存；独立 Gemini 与 WorkBuddy 会话使用当前 Windows 用户的 DPAPI 加密。WorkBuddy 只在内存中处理授权结果，令牌不会写进配置或日志。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。用于还原排版的 HTML 原文与纯文本正文一样只保存在内存中，不写入数据目录；验证码处于隐藏状态时会丢弃 HTML 原文，避免从未遮蔽的原文里读到验证码。不要将运行中的内存转储公开分享。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

点击「检查更新」时，程序会访问 GitHub 的公开发布接口，并在请求头中包含岛仔版本号，不发送本地设置、邮箱或日程数据。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\Daozai\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

程序不使用统一的岛仔云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由岛仔自己的安全存储管理。不要把访问令牌、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。

## 反馈安全问题

请使用仓库的私密漏洞报告入口，见 [SECURITY.md](../SECURITY.md)。普通 UI 问题可以开公开 Issue，但请先去除敏感信息。
